# Smart FYP Validator 🚀

An AI-powered Final Year Project (FYP) uniqueness validator, smart architectural upgrade engine, and defense simulator designed for Computer Science & Engineering students.

## ✨ Features
- **Uniqueness Validator:** Check your project idea against existing datasets to avoid duplication.
- **Architectural Upgrade Engine:** Receive AI-driven recommendations to scale and improve your project's architecture.
- **Defense Simulator:** Practice answering tough questions and defending your FYP before the actual presentation.

## 🛠️ Tech Stack
- **Frontend:** React / Vite (or TypeScript-based frontend)
- **Backend:** Node.js (`server.ts`)
- **AI Integration:** Powered by Google Gemini / AI Studio
